# Web to Figma

浏览器扩展：抓取当前网页，导出供设计还原使用的 JSON 数据。

## 安装

1. 下载本仓库并解压，或使用 Git 克隆。
2. 在 Chrome 扩展管理页面 `chrome://extensions` 打开「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择包含 `manifest.json` 的文件夹。

## 使用

1. 打开需要抓取的网页，点击扩展图标。
2. 扩展会自动滚动页面，等待图片和字体加载，然后抓取页面内容。
3. 保存生成的 `figma-capture-时间戳.json` 文件。

本仓库仅包含网页抓取扩展，未包含将导出 JSON 导入 Figma 的配套插件。导出的 JSON 不是 `.fig` 文件。

## 文件

- `manifest.json`：扩展配置及权限声明。
- `background.js`：点击扩展后注入脚本并下载结果。
- `runner.js`：滚动页面、等待资源并调用抓取函数。
- `capture.js`：页面抓取脚本。
- `logo/`：扩展图标。

## 权限

扩展声明 `activeTab`、`scripting` 和 `downloads` 权限，分别用于访问当前标签页、运行抓取脚本和下载结果。

## 验证范围

上传时保留原始功能代码，未进行浏览器端运行验证。
